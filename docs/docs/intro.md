# Introduction

🛒 ⚙️ [VTEX](https://vtex.com) platform .NET SDK.

The VTEX SDK for .NET lets you call the VTEX platform APIs from your .NET applications.

## Installation

```bash
dotnet add package VTEX
dotnet add package VTEX.Health
```

## Source code

The source code, issues and releases live on [GitHub](https://github.com/guibranco/VTEX-SDK-dotnet).
